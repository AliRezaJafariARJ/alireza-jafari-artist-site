====================================================

محتویات بسته
- index.html : صفحه اصلی دو زبانه فارسی و انگلیسی
- assets/alireza-portrait.jpg : تصویر اصلی
- assets/alireza-seaside.jpg : تصویر دوم

نکته مهم
برای نمایش صحیح هر دو عکس، فایل index.html را از داخل همین پوشه و همراه پوشه assets نگه دارید. فایل HTML را به‌تنهایی جابه‌جا نکنید. برای تست، ابتدا ZIP را کامل Extract/استخراج کنید و سپس index.html را باز کنید.

انتشار رایگان با GitHub Pages
1) در GitHub یک حساب کاربری بسازید یا وارد حساب شوید.
2) یک Repository جدید بسازید. برای آدرس اصلی رایگان می‌توانید نام Repository را دقیقاً username.github.io بگذارید (به جای username نام کاربری GitHub خودتان).
3) تمام محتویات این پوشه، یعنی index.html و پوشه assets را در ریشه Repository بارگذاری کنید؛ خود فایل ZIP را به‌جای محتویات آن بارگذاری نکنید.
4) در Settings > Pages، گزینه انتشار از شاخه main و پوشه /(root) را انتخاب و ذخیره کنید.
5) پس از آماده شدن انتشار، سایت با نشانی https://username.github.io در دسترس خواهد بود.

جست‌وجوی گوگل
- بعد از انتشار، آدرس سایت را در Google Search Console ثبت و مالکیت آن را تأیید کنید.
- سپس آدرس صفحه اصلی را برای ایندکس درخواست دهید.
- ثبت در گوگل و نمایش در نتایج تضمینی یا فوری نیست؛ زمان و رتبه به فرایند ایندکس و عوامل سئو بستگی دارد.

شنیدن و دانلود آثار
دکمه‌های هر قطعه به لینک ساندکلاد همان قطعه می‌روند. امکان دانلود رایگان هر قطعه را تنظیمات مجوز دانلود همان ترک در SoundCloud تعیین می‌کند؛ این سایت به‌تنهایی مجوز دانلود ایجاد نمی‌کند.
